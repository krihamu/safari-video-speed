# Safari 视频倍速书签

点击书签，把当前网页中的第一个 HTML 视频在 **1 倍速与 3 倍速**之间切换。不需要安装浏览器扩展。

## 安装

1. 在 Safari 中把任意网页添加为书签，命名为「视频 3 倍速」。
2. 打开「书签 → 编辑书签」，找到刚添加的书签，编辑它的地址。
3. 将 `bookmarklet.txt` 中的整行内容复制到地址中，替换原来的网址。保留开头的 `javascript:`。
4. 保存，打开有视频的网页，点击这个书签即可。

## 使用与原理

脚本通过 `document.querySelector('video')` 找到页面中的第一个视频。`playbackRate` 就像播放器的速度旋钮：1 是正常速度，3 是三倍速度。

如果当前是三倍速，点击后恢复一倍速；如果当前是其他速度，点击后切换到三倍速。脚本同时设置 `defaultPlaybackRate`，并弹窗提示结果。没有找到视频时会提示「未找到视频」。

## 文件

- `bookmarklet.txt`：可直接粘贴到书签地址的原始脚本。
- `video-speed.js`：方便阅读和修改的源码，行为与书签脚本一致。

## 适用范围

- 只处理当前文档中的第一个 `<video>` 元素，不会处理所有视频。
- 不会进入 iframe 或 Shadow DOM 查找视频。
- 部分网站可能限制书签脚本或自行重置播放速度。
- 不会将视频下载到本地，也不会上传任何数据；刷新页面后可能需要重新点击。

本仓库保留用户提供的脚本行为；尚未对具体视频网站进行兼容性测试。
